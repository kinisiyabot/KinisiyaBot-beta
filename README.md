## 🔥 كيف تشغلو ترمكس

```bash
termux-setup-storage
```

```bash
apt update && apt upgrade && pkg install -y git nodejs ffmpeg imagemagick
```

**نزّل البوت من جيت هب:**

```bash
cd /sdcard/.bot
git clone https://github.com/kinisiyabot/KinisiyaBot-beta.git bot
cd bot
```

**نزّل المكتبات:**

```bash
npm install
```

**شغّل البوت:**

```bash
npm start
```

> 📖 **مرجع الـ API الكامل** (كل البلوجنات + نماذج الاستجابة): [`docs/API.md`](docs/API.md)

## 🛠️ نظام التصحيح الذاتي (Self-Healing)

البوت يراقب أخطاء التشغيل بنفسه. عند حدوث خطأ حقيقي يُرسل للمطور على واتساب
تقريراً فيه التفاصيل وزرّي *نعم / لا*:

- **نعم** → يُعيد تحميل البلوجن المتسبب ثم يُعيد تشغيل نفسه (restart).
- **لا** → يتجاهل الخطأ.
- مدة الرسالة **5 دقائق**؛ بعدها تنتهي الموافقة تلقائياً.

طرق الرد: زر *نعم/لا*، أو الأمر `.selfheal <id>` / `.selfheal-no <id>`،
أو ردّ نصّي "نعم/لا" في الخاص.

حمايات مدمجة: تجاهل أخطاء الاتصال المتوقّعة (QR/انقطاع الشبكة)، منع تكرار
نفس الخطأ، تهدئة دقيقة بين التنبيهات، وحماية من حلقة إعادة تشغيل لا نهائية.
للتعطيل: شغّل بـ `node index.js --no-selfheal`.
